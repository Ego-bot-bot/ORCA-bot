# ORCA Bot

VK-бот для удалённого управления квантово-химическими расчётами ORCA.
Настраивайте `.inp`-файлы, запускайте расчёты, следите за прогрессом —
всё через сообщения ВКонтакте, прямо с телефона.

## Возможности

- 📋 **Просмотр `.inp`** — все файлы в рабочей папке со статусами.
- ✏️ **Редактирование** — методы, базисы, растворители, заряды,
  мультиплетности, типы задач.
- ✅ **Валидация** — бот предупредит о несовместимых параметрах
  перед запуском.
- 🚀 **Запуск** — один файл или все ожидающие сразу.
- 📊 **Мониторинг** — прогресс, ошибки, зацикливание, зависания.
- ⏹ **Управление** — остановка текущего расчёта, очистка очереди.
- 🧹 **Автоочистка** — временные файлы ORCA удаляются после расчёта.
- 🔔 **Уведомления** — после каждой задачи и о новых `.inp`.
- 👥 **Мульти-режим** — несколько пользователей с одного бота.

## Требования

- **ОС:** Windows 10/11
- **Python:** 3.11+
- **ORCA:** 6.0+ (`orca.exe` должен быть установлен)
- **Avogadro:** 2.0+ (для рисования молекул, опционально)
- **VK-сообщество** — создаётся бесплатно за 5 минут

## Установка

### 1. Клонирование и окружение

```bash
git clone <url-репозитория>
cd <папка-проекта>

python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Создание VK-сообщества

VK-бот работает от имени **сообщества**. Создайте своё.

#### Шаг 2.1. Создайте сообщество

1. Откройте [vk.com/groups](https://vk.com/groups).
2. Нажмите **«Создать сообщество»**.
3. Тип: **«Бизнес»** (или любой другой).
4. Название — любое, например `Мой ORCA Bot`.
5. Нажмите **«Создать»**.

#### Шаг 2.2. Включите сообщения

1. Управление сообществом → **«Сообщения»**.
2. Включите **«Сообщения сообщества»**.

#### Шаг 2.3. Получите токен

1. Управление → **«Работа с API»** → **«Создать ключ»**.
2. Отметьте права:
   - ✅ **Управление сообществом**
   - ✅ **Сообщения сообщества**
3. Нажмите **«Создать»**.
4. **Скопируйте токен** (строка вида `vk1.a.…`).
   ⚠️ Показывается только один раз!

#### Шаг 2.4. Узнайте ID сообщества

1. Откройте главную страницу сообщества.
2. URL: `vk.com/club123456789` → число `123456789` = **ID**.

#### Шаг 2.5. Узнайте свой VK ID

1. Настройки → **«Номер страницы»**.
2. Скопируйте число — это ваш личный `user_id`.

### 3. Создание `bot_config_secret.py`

Скопируйте шаблон:

```bash
copy bot_config_secret.py.example bot_config_secret.py
```

Откройте `bot_config_secret.py` и впишите свои данные:

```python
VK_TOKEN    = "vk1.a.ВАШ_ТОКЕН"
VK_GROUP_ID = 123456789
VK_USER_ID  = 288172397
```

⚠️ **Этот файл нельзя коммитить в git** — он в `.gitignore`.

### 4. Настройка путей в `bot_config.py`

Откройте `bot_config.py` и укажите:

```python
ORCA_EXE = r"C:\ORCA_6.1.0\orca.exe"
WORK_DIR = r"C:\Users\Me\Desktop\ORCA_inputs"
```

- `ORCA_EXE` — полный путь к `orca.exe`.
- `WORK_DIR` — папка, куда вы сохраняете `.inp` из Avogadro.

### 5. Первый запуск

1. Дважды кликните **`run_bot.bat`**.
2. В VK придёт сообщение `🤖 ORCA Bot запущен`.
3. Если не приходит — откройте диалог с сообществом
   и нажмите **«Разрешить сообщения»**.
4. Отправьте боту `/help`.

**Ожидаемый вывод консоли:**

```
============================================================
ORCA Bot запускается (мульти-режим)...
============================================================
[+] Рабочая папка: C:\Users\...\ORCA_inp_py
[+] Подписчиков: 1
[+] VK готов (group=241965773)
[+] Worker запущен
[+] Watcher запущен (каждые 30 сек)
[+] Слушаю команды... (Ctrl+C для выхода)
```

## Команды бота

### Подписка

| Команда | Что делает |
|---|---|
| `/start` | Подписаться на уведомления |
| `/unsubscribe` | Отписаться |
| `/whoami` | Показать свой VK user_id |
| `/subscribers` | Список подписчиков (только владелец) |

### Просмотр

| Команда | Что делает |
|---|---|
| `/list` | Все `.inp` в папке со статусами |
| `/show <file>` | Содержимое файла + текущие параметры |
| `/status` | Что считается сейчас |
| `/queue` | Список задач в очереди |

### Настройка `.inp`

| Команда | Что делает |
|---|---|
| `/set <file>` | Проверить валидацию, не меняя |
| `/set <file> task Opt` | Установить тип задачи |
| `/set <file> theory B3LYP` | Установить метод |
| `/set <file> basis def2-TZVP` | Установить базис |
| `/set <file> dispersion D4` | Dispersion correction |
| `/set <file> solvent benzene` | Растворитель |
| `/set <file> model SMD` | Модель сольватации |
| `/set <file> charge -1` | Заряд молекулы |
| `/set <file> mult 1` | Мультиплетность |
| `/delete <file>` | Удалить `.inp`, `.out`, `.bak` |

### Запуск

| Команда | Что делает |
|---|---|
| `/run <file>` | Запустить один файл |
| `/run all` | Запустить все ожидающие |
| `/stop` | Остановить текущий расчёт |
| `/stop all` | Остановить + очистить очередь |
| `/stop <file>` | Убрать конкретный файл из очереди |

### Справка

| Команда | Что делает |
|---|---|
| `/methods` | 24 метода с пояснениями |
| `/bases` | 20 базисов |
| `/tasks` | 6 типов задач |
| `/solvents` | 14 растворителей |
| `/models` | 6 моделей сольватации |
| `/disp` | Dispersion corrections |
| `/charge` | Что такое заряд |
| `/mult` | Что такое мультиплетность |
| `/help` | Полный список команд |

## Workflow

### 1. Нарисуйте молекулу

В **Avogadro** создайте структуру и сохраните её как `.inp` в папку
`WORK_DIR`, указанную в `bot_config.py`.

### 2. Настройте через бот

```
/set mol1.inp task Opt
/set mol1.inp theory r2SCAN-3c
/set mol1.inp charge 0
/set mol1.inp mult 1
```

Бот применит изменения и покажет комментарий валидации:

```
✏️ mol1.inp: task = Opt

✅ Совместимость в порядке
ℹ️ После Opt — проверьте частоты
   Рекомендую запустить Freq: проверить, что все частоты
   положительные (это минимум, а не TS).
```

### 3. Запустите расчёт

```
/run mol1.inp
```

Бот создаст копию `mol1_Opt.inp`, запустит ORCA и пошлёт
уведомление о старте.

### 4. Следите за прогрессом

```
/status
→ ⏳ Считается: mol1_Opt.inp
  В очереди: 0

/queue
→ 📋 Очередь (2):
  1. mol2_Freq.inp
  2. mol3_Opt.inp
```

### 5. Получите уведомление

После завершения расчёта придёт сообщение:

```
🔔 ✅ Готово: mol1_Opt.inp

Время: 12м 34с
Файл:  mol1_Opt.out
```

## Что удаляется после расчёта

**Удаляется автоматически:**

| Файл | Что это |
|---|---|
| `*.bas*` | Разложение базиса (большие) |
| `*.pc*` | Pre-computed integrals |
| `*.tmp`, `*.tmp2` | Временные |
| `*.dat` | Служебные |
| `*.cpcm`, `*.scfpcm`, `*.scf` | PCM scratch |
| `*.c`, `*.d` | ORCA scratch |
| `*.input` | Копия `.inp` от ORCA |
| `*.densitiesinfo` | Метаданные плотности |
| `*.hostname` | Служебный |

**Сохраняется всегда:**

| Файл | Что это |
|---|---|
| `*.inp` | Входной файл |
| `*.out` | Главный лог расчёта |
| `*.xyz` | Геометрия |
| `*.gbw` | Волновая функция |
| `*.hess` | Матрица Гессе (если Freq) |
| `*.trj.xyz` | Траектория (NEB/IRC) |

Очистка управляется в `bot_config.py`:

```python
CLEANUP_ENABLED = True
DELETE_PATTERNS = [...]
DELETE_FOLDERS = [...]
```

Отключить: `CLEANUP_ENABLED = False`.

## FAQ

### Не приходят уведомления в VK

Откройте диалог с сообществом → нажмите **«Разрешить сообщения»**.
VK требует явного согласия пользователя.

### Бот не отвечает на команды

1. Проверьте, что `run_bot.bat` запущен.
2. Если ваш токен использует кто-то ещё — LongPoll будет
   конфликтовать. Только один бот на токен.

### SCF завис / расчёт не сходится

Бот убьёт расчёт после `MAX_SCF_ITER_WARN` итераций
(по умолчанию 200). Порог настраивается в `bot_config.py`:

```python
MAX_SCF_ITER_WARN   = 200
MAX_OPT_CYCLES_WARN = 100
STALL_TIMEOUT_MIN   = 90
MAX_RUNTIME_HOURS   = 48
```

### Как узнать свой VK ID

В боте: `/whoami`.

### Работает ли мульти-режим

Да. Несколько человек могут писать одному боту, если он запущен
на **одном ПК**. У каждого свой диалог, уведомления рассылаются
всем подписчикам.

### Как добавить друга вручную

Откройте `subscribers.json`:

```json
{
  "users": [288172397, 123456789]
}
```

Друг должен узнать свой ID (например, через `/whoami` в любом
другом боте или в настройках своего VK).

### Ошибка «Папка не найдена»

Проверьте `WORK_DIR` в `bot_config.py` — путь должен существовать.

### Краказябры в консоли вместо русских букв

Добавьте в начало `run_bot.bat`:

```bat
chcp 65001 > nul
```

### Конфликт с другим VK-ботом

VK допускает только одно LongPoll-подключение на токен.
Закройте остальные экземпляры бота с тем же токеном.

## Безопасность

### ⚠️ Никогда не коммитьте `bot_config_secret.py`

Там ваш VK-токен. Проверьте `.gitignore`:

```
bot_config_secret.py
subscribers.json
```

### Если токен уже светился

Отзовите его и создайте новый:

1. Управление сообществом → **«Работа с API»**.
2. Рядом с ключом → **«Отозвать»**.
3. **«Создать ключ»** заново.
4. Обновите `bot_config_secret.py`.

### Проверка перед публикацией

```bash
git status
```

В списке **не должно быть**:
- `bot_config_secret.py`
- `subscribers.json`
- `*.out`, `*.inp`, `*.log`
- `.venv/`
